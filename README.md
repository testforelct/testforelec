# ELECTRANS website (prototype)

Static starter site for GitHub Pages. All text is placeholder.

| File | Page |
|---|---|
| index.html | Home |
| about.html | About |
| overview.html | Project Overview |
| submission-info.html | Submission Information |
| submit.html | Submission page (Tally form embed, ID `lbJOjv`) |
| faq.html | FAQs |
| style.css | Shared styles (edit colors at the top) |

To publish: upload all files to the root of the `electrans.github.io` repo, then Settings > Pages > Deploy from branch `main` / root.
